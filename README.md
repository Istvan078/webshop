# Webshop 🛒  
### ⚡Link: https://webshop0781.web.app/

An Angular-based e-commerce application with a scalable **NgRx** state architecture, **Firebase** backend, and **SCSS** styling.

Built to demonstrate a clean shopping flow, category browsing, product highlights, and a modern state-driven frontend approach.

---

## ✨ Features
- 🏠 Home page with featured / discounted products
- 🗂️ Category & subcategory navigation
- 🔎 Product search
- 🧾 Product listing + details (price, discount, description)
- 🛒 Cart management (add/remove/update quantity)
- 🔐 Authentication (Register / Login)
- 🔔 Admin Page to view orders
- ⚡ State-driven UI with NgRx (predictable, scalable data flow)

---

## 🧱 Tech Stack
- **Frontend:** Angular
- **State management:** NgRx (Store, Actions, Reducers, Effects)
- **Backend:** Firebase (Auth + Firestore / Realtime DB)
- **Styling:** SCSS
- **Deployment:** Firebase Hosting
